# Newtons Notebook - A Fun game to teach physics

Projektkurs-Q2 is a C# game built as a school project course (Projektkurs, Q2). Instead of reading formulas, players learn physical concepts by interacting with them directly.

## Highlights

- **Learning by playing:** physics concepts are part of the gameplay, not a quiz on the side
- **Learn about Torque and Rotational Speed** Interactive game to teach students how Gears can be used to control the rotational speed or torque
- **Electrical systems sandbox** Quest guided circuit builder opening up to a circuit assembly sandbox
- **Comprehensive writteb guid pages** To freshen up on theoretical concepts or for more textbook learners
