# Newtons Notebook - A fun game to teach physics

Newtons Notebook is a C# game built as a school project course (Projektkurs, Q2). Instead of reading formulas, players learn Physics concepts by interacting with them directly.

## Highlights

- **Learning by playing:** physics concepts are part of the gameplay, not a quiz on the side
- **Torque and rotational speed:** Interactive game to teach students how Gears can be used to control the rotational speed or torque
- **Electrical systems sandbox:** A quest-guided circuit builder that unlocks a free circuit sandbox
- **Comprehensive written guides:** Theory pages for refreshing concepts, or for learners who prefer a textbook approach
